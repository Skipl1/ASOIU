# Старые браузеры для проверки совместимости АС ГРСН

ТЗ (п. 4.4) требует поддержку Google Chrome 90+, Mozilla Firefox 88+ и Microsoft Edge 90+. Для проверки на минимальных версиях здесь используются портативные браузеры, которые не устанавливаются в систему и не обновляются:

- **Chromium 90.0.4430.0**: движок Chrome 90 и Edge 90;
- **Firefox 88.0**: русская версия, автообновление отключено.

Сами браузеры в git не хранятся (около 620 МБ, отдельные файлы больше 100 МБ GitHub не принимает).

## Установка на новом компьютере (Windows 10/11)

Дважды щёлкните `install_browsers.bat` или выполните:

```
powershell -ExecutionPolicy Bypass -File brouser\install_browsers.ps1
```

Скрипт скачивает браузеры с официальных серверов (Google, Mozilla) и проверяет подпись установщика Firefox. Он распаковывает их в `chromium90\` и `firefox88\` и создаёт отдельные профили в `profiles\`. Повторный запуск безопасен, ключ `-Force` переустанавливает браузеры.

## Запуск

- `Chromium 90.bat` — открывает http://localhost:8080 в Chromium 90;
- `Firefox 88.bat` — открывает http://localhost:8080 в Firefox 88.

Версию можно проверить на страницах `chrome://version` и `about:support`.
